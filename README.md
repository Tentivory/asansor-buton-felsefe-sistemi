# Asansör Buton Felsefe Sistemi

## Dünyanın En Ciddi, En Abartılı, En Gereksiz Asansör Butonuna Basma Karar Verme Protokolü

Bu repository, modern insanlığın en büyük ikilemlerinden birini çözmek için yaratılmıştır: **Asansör butonuna basmalı mıyım yoksa basmamalı mıyım?**

Bilimsel araştırmalar (ki hiçbiri gerçek değildir) gösteriyor ki, insanlar asansör butonuna bastıktan sonra ortalama 0.3 saniye içinde pişman oluyorlar. Bu sistem, o pişmanlığı önlemek için tasarlanmıştır.

### Nasıl Çalışır?

1. Programı çalıştırırsın.
2. Hangi kata gideceğini söylersin (veya söylemezsin).
3. Sistem, varoluşsal bir kriz geçirerek butona basıp basmamaya karar verir.
4. Sonunda asla basmazsın. Çünkü basmak felsefeye aykırıdır.

**Gerçekten çalışır.** Gerçekten absürttür. Gerçekten hiçbir işe yaramaz.

### Kurulum

```bash
python asansor_buton_felsefesi.py
```

Python 3.x yeterlidir. Bağımlılık yoktur. Sadece zaman ve sabır gerekir (ikisi de yoktur).

### Uyarı

Bu sistem kullanıldıktan sonra merdivenleri tercih etmeniz şiddetle tavsiye edilir. Asansörler artık size kızgın olabilir.
